# YachtWay
## React + TypeScript + Vite


For run project locally install this [extension](https://chromewebstore.google.com/detail/allow-cors-access-control/lhobafahddgcelffkeicbaginigeejlf)

In the settings of the extension "Open options page" make sure that the checkbox on 4th place "Access-Control-Allow-Credentials" checked to be true

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
